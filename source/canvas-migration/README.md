# Canvas migration (historical, one-time)

This is the pipeline that parsed the original Canvas export
(`~/Desktop/csa-2025-26-export/course_settings/module_meta.xml`) into the
first version of this site. It's kept here for provenance — it is **not**
part of the ongoing content workflow anymore.

Going forward, edit content in `content/*.md` and run `source/build_from_markdown.py`
(or just `./publish.sh` from the repo root). See the top-level `README.md`.
