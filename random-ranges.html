      Show me the pattern

// Math.random() gives a double from 0.0 up to (but never) 1.0
// low to high, inclusive. The count of values is (high - low + 1).
int value = (int)(Math.random() * (high - low + 1)) + low;

// Random does the same job with the count passed straight in
Random rand = new Random();
int value = rand.nextInt(high - low + 1) + low;


      
Figure out how many values you need first, then where they start. For -3 to 8 the count is 8 - (-3) + 1 = 12, so you want 12 values starting at -3.

    


    

      Watch out for this one
      (int)Math.random() * 6 compiles, but it always gives 0. The cast only applies to Math.random(), so it becomes 0 before you multiply. Type it in and you will see one bar.
